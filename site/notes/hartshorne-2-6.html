1 2.6

Providing some motivation is good. Long time ago, with the aim of studying rational functions on compact Riemann surfaces S, the following space of functions was introduced

M(n1p1 + ⋯ + nkpk) := {rational functions f : S → ℙ1 such that  ord ⁡ pi(f) ≥−ni}.

Where ni ∈ ℤ, pi ∈ S and

ord ⁡ p(f) = {a f has a zero of order a at p − af has a pole of order a at p 0 Other

Later, the notion of the divisor group was introduced,that is, Div ⁡ (S) := ℤ[S], whose elements are formal linear sums of points on S with integer coefficients. Then, to each rational function f, we associate a divisor denoted by div ⁡ (f) := ∑ ⁡ s∈S ord ⁡ p(f) ⋅ p. This is a finite sum because S is compact, hence well-defined. A divisor D is called effective if each coefficient is non-negative, denoted by D ≥ 0.

Then, let D := n1p1 + ⋯ + nkpk be a divisor, we can rewrite the above space of functions as follows

M(D) = {rational functions f : S → ℙ1 such that  div ⁡ (f) + D ≥ 0}.

Riemann noticed that the dimension of this space is extremely important. He discovered an inequality that relates the dimension of the space of functions h0(D) := dim ⁡ ℂM(D), the numerical information of the divisor deg ⁡ D := ∑ ⁡ ni and the genus g(S) of the compact Riemann surface S, as follows

h0(D) ≥ deg ⁡ D + 1 − g(S).

Later, Riemann’s student Roch completed the inequality into an equality as follows

h0(D) − h0(K − D) = deg ⁡ D + 1 − g(S).

Where K denotes the canonical divisor on S, which is associated with the holomorphic 1-forms on S.

1.1 Cartier divisor

Let X be a variety over field k. Here, we develop the correspondence between Cartier divisors, the line bundle associated with a Cartier divisor, and the embedding of such bundles into the function field. We begin by considering codimension-one closed subschemes of X that are locally defined by a single function.

Consider an open cover X = ⋃ ⁡ iUi, and pick fi ∈Γ(Ui,𝒪X) ⊂ K(X) satisfying fi fj ∈Γ(Ui ∩ Uj,𝒪X)×. According to our choice, the zero set of fi

V (fi) = {x ∈ Ui|(fi)x ∈𝔪x ⊂𝒪X,x}⊂ Ui

is a closed subscheme in Ui satisfy V (fi) ∩ Uj = V (fj) ∩ Ui. So we obtain a closed subscheme D on X. We denote D = {(Ui,fi)}i.

This collection of data induces a line bundle on X. For each Ui, we can define a subsheaf of the function field of Ui, that is, 𝒪Ui ⋅ 1 fi ⊂𝒦X|Ui, with transition functions

φ𝑖𝑗 : (𝒪Ui ⋅ 1 fi)|Ui∩Uj ≅(𝒪Uj ⋅ 1 fj)|Ui∩Uj si fi ↦si fi.

Therefore these locally defined sheaves can be glued together to get a line bundle 𝒪X(D) on X with isomorphism 𝒪 ⁡ (D)|Ui≅ ⁡ 𝒪Ui ⋅ 1 fi. Each section s ∈Γ(V,𝒪X(D)) is of the form s = {(Ui ∩ V, gi fi)} such that gi fi = gj fj on Ui ∩ Uj ∩ V . Similarly, by gluing the local sheaf 𝒪Ui ⋅ fi together, we obtain an idea sheaf ID ⊂𝒪X. We can see that ID is also a line bundle such that 𝒪X(D) ⊗ID≅𝒪 ⁡ and D = V (ID).

Let’s descrive the embedding of 𝒪X(D) into the sheaf of rational functions 𝒦X. Note that we have an injection

𝒪X↪𝒦X.

Tensoring 𝒪X(D), we have

𝒪X(D)↪𝒪X(D) ⊗𝒦X.

If D = {(Ui,fi)}, then we obtain an isomorphism as following

𝒪X(D) ⊗𝒦X ≅𝒦X {(Ui ∩ V, gi fi ⊗ a)} ↦{(Ui ∩ V,a ⋅gi fi)}.

Note that these locally defined functions {(Ui ∩ V,a ⋅gi fi)} patch together to define a rational function a ⋅g f ∈Γ(V,𝒦X) = K(X) such that (a ⋅g f)|Ui = a ⋅gi fi. Combined with this isomorphism, we have

𝒪X(D)↪𝒦X.

Therefore, the sections of 𝒪X(D) can be equivalently desctibed as follows

Γ(V,𝒪X(D)) = {f ∈ K(X) such that f|Ui ⋅ fi ∈𝒪Ui} = {f ∈ K(X) such that f|V ⋅Γ(V,ID) ⊂Γ(V,𝒪X)} = {f ∈ K(X) such that  div ⁡ (f)|V + D|V ≥ 0}.

Where div ⁡ (f) = {(X,f)} and div ⁡ (f)|V + D|V = {(Ui,f|Ui ⋅ fi)}≥ 0 means that f|Ui ⋅ fi ∈𝒪Ui. So we can see that the sections of 𝒪X(D) are the rational functions that has no poles worse that D.

Example 1.1.1. Setting X = ℙk1, U0 = D+(x0) = Spec ⁡ k[x1 x0], U1 = D+(x1) = Spec ⁡ k[x0 x1], f0 = x1 x0, f1 = 1. Then we have a Cartier divisor D = {(U0,f0), (U1,f1)}. If we pick f0 = 1, f1 = x0 x1 and let L′ be the corresponding line bundle, it can be shown in the same manner as above that

1.2 Weil divisor

Let X be a variety over field k. Recall that an effective Cartier divisor of X can be viewed as a closed subscheme of X such that it is locally cut out by a single function. But not every codimensional-one closed integral subscheme is of this form. In fact, we have

Proposition 1.2.1. Let X be the variety as above. Then the following are equivalent.

(1) X is locally factorial.

(2) Every closed integral subscheme of X is locally defined by a single function.

This proposition is just the geometric version of the following lemma

Lemma 1.2.2. A a noetherian integral domain. Then A is factorial if and only if every prime of height 1 is a principal ideal.

Now, let us define the associated sheaf of a Weil divisor.

Definition 1.2.3. Let X be a normal variety, K(X) the function field. Given a Weil divisor D, define 𝒪X(D) to be the sheaf such that

Γ(V,𝒪X(D)) = {f ∈ K(X)| div ⁡ (f)|V + D|V ≥ 0}∪{0}.

By ” ≥ ”, I mean that div ⁡ (f)|V + D|V is effective on V .

Note that 𝒪X(D) is in fact a coherent sheaf, though I omit the proof here.

Let U be the regular locus of the normal variety X, let j : U → X denote the open immersion. Then 𝒪X(D)|U restricts to a line bundle over U. Moreover we have

Definition 1.2.4. Let X be a vairety over k. A coherent sheaf F is called reflexive, if the canonical map F →F∨∨ is an isomorphism. By a reflexive sheaf of rank n, I mean a reflexive sheaf whose stalk at the generic point is a vector space of dimension n.

1.3 Example

Example 1.3.1. Let X be a regular in codimension-one k-variety and let π : X × 𝔸1 → X be the projection. Then X × 𝔸1 is also a regular in codimension-one variety and Cl ⁡ (X × 𝔸1)≅ ⁡ Cl ⁡ (X).

First, we must show that there are only two types of codimension-one closed subschemes on X × 𝔸1, that is, ’vertical’ and ’horizontal’ divisors. By taking an affine open cover {Ui} of X × 𝔸1, the problem reduces to determining the height one prime ideal of R[t]. Let K be the fraction field of R.

Let 𝔅 ∈ Spec ⁡ R[t] be a height one prime ideal. Since ht ⁡ R(𝔅 ∩ R) ≤ ht ⁡ R[t](𝔅), there are only two cases to consider.

If ht ⁡ R(𝔅 ∩ R) = 1, let 𝔭 = 𝔅 ∩ R, we get a chain of prime ideal

(0) ⊂𝔭𝑅[t] ⊂𝔅.

It follows that 𝔭𝑅[t] = 𝔅, a vertical divisor. Note that

R[t]𝔭𝑅[t] = (R𝔭[t])𝔭R𝔭[t],

where R𝔭 is a DVR and hence 𝔭R𝔭[t] is a principal ideal, which implies that (R𝔭[t])𝔭R𝔭[t] is also a DVR.

If ht ⁡ R(𝔅 ∩ R) = 0, then 𝔅 ∩ R = (0). Let S = R ∖{0}, then S−1R[t] = K[t] and 𝔅𝐾[t] = (f(t)), where f ∈ K[t]. So we have 𝔅 = R[t] ∩ f(t)K[t], a horizontal divisor. Note that we have

R ∖{0}⊂ R ∖𝔅.

So we get

R[t]𝔅 = K[t](f),

a DVR.

We next prove that any horizontal divisor is linearly equivalent to a sum of vertical divisors. Let a ∈ R be a regular element such that a ⋅ f ∈ R[t], then it follows that 𝔅Ra[t] = (f(t)). Since V (a) ⊂ Spec ⁡ R[t] is a codimension one closed subscheme, we have the following sequence

⊕ Fiℤ[Fi] → Cl ⁡ (R[t]) → Cl ⁡ (Ra[t]) → 0.

Where the Fi are irreducible components of V (a). Let D be the divisor on Spec ⁡ R[t] corresponding to the ideal 𝔅. Since the image of D in Cl ⁡ (Ra[t]) is 0, we have

D ∼∑ ini[Fi],

as expected.

Note that we have a map π∗ : Cl ⁡ (X) → Cl ⁡ (X × 𝔸1) given by

D = ∑ ini[Y i]↦∑ ini[π−1(Y i)].

The discussion above implies that π∗ is surjective. If π∗D = ∑ ⁡ ini[π−1(Y i)] = div ⁡ (f) for some f ∈ K(t). Let U = X ∖ (⋃ ⁡ iY i) we see that div ⁡ (f)|U×𝔸1 = 0 on U × 𝔸1. It follows that f is an invertible element in K[t]. So f ∈ K× and D = div ⁡ (f). So π∗ is an injection.
