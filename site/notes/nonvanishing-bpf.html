Nonvanishing

This section proves the following theorem

Theorem 1 (Nonvanishing). Let (X,Θ)(X,\Theta) be a sub-klt pair where XX is a projective variety. Let DD be a nef Cartier divisor and assume that A:=aD−KX−ΘA:=aD-K_X-\Theta is nef and big for some a>0a>0. Then we have H0(X,mD+⌈−Θ⌉)≠0H^0(X,mD+\lceil -\Theta\rceil)\neq 0 for m≫0m\gg 0.

First we can reduce the proof to the case when XX is smooth, Θ\Theta SNC and A:=aD−KX−ΘA:=aD-K_X-\Theta ample: Take log resolution f:Y→Xf:Y\to X such that:

(1) YY is projective smooth;

(2) KY+ΘY=f*(KX+Θ)K_Y+\Theta_Y=f^*(K_X+\Theta);

(3) supp⁡ΘY\operatorname{supp}\Theta_Y is SNC.

Since f*(A)=f*(aD−KX−Θ)=af*D−(KY+ΘY)f^*(A)=f^*(aD-K_X-\Theta)=af^*D-(K_Y+\Theta_Y) is nef and big, then take kk sufficiently large such that f*A≡H+1kEf^*A\equiv H+\frac{1}{k}E where HH is ample, EE is effective and (Y,ΘY+1kE)(Y,\Theta_Y+\frac{1}{k}E) is still sub-klt. Then f*A−1kE=af*D−(KY+ΘY+1kE)≡Hf^*A-\frac{1}{k}E=af^*D-(K_Y+\Theta_Y+\frac{1}{k}E)\equiv H is ample. We see that −ΘY−1kE≤−ΘY-\Theta_Y-\frac{1}{k}E\le -\Theta_Y and f*(⌈−ΘY⌉)≤⌈−Θ⌉f_*(\lceil -\Theta_Y\rceil)\le \lceil -\Theta\rceil, hence we have the following injections H0(Y,mf*D+⌈−ΘY−1kE⌉)→H0(Y,mf*D+⌈−ΘY⌉)→H0(X,mD+⌈−Θ⌉)H^0(Y,mf^*D+\lceil -\Theta_Y-\frac{1}{k}E\rceil)\to H^0(Y,mf^*D+\lceil -\Theta_Y\rceil)\to H^0(X,mD+\lceil -\Theta\rceil) After replacing XX, AA, Θ\Theta by YY, f*Af^*A, ΘY+1kE\Theta_Y+\frac{1}{k}E, we can assume that XX is projective smooth, Θ\Theta is SNC and A:=aD−KX−ΘA:=aD-K_X-\Theta is ample.

Theorem 5 (Nonvanishing: smooth). Let XX be a smooth projective variety, DD a nef Cartier divisor and Θ\Theta an SNC divisor with coefficients less than 11. Assume that A:=aD−KX−ΘA:=aD-K_X-\Theta is ample for some a>0a>0. Then we have H0(X,mD+⌈−Θ⌉)≠0H^0(X,mD+\lceil -\Theta\rceil)\neq 0 for m≫0m\gg 0.

Proof. If D≡0D\equiv 0 then H0(X,mD+⌈−Θ⌉)=χ(X,mD+⌈−Θ⌉)=χ(X,⌈−Θ⌉)=H0(X,⌈−Θ⌉)≠0.H^0(X,mD+\lceil -\Theta\rceil)=\chi(X,mD+\lceil -\Theta\rceil)=\chi(X,\lceil -\Theta\rceil)=H^0(X,\lceil -\Theta\rceil)\neq 0. Where the middle equality is by Riemann-Roch theorem and the first and last equality is by Kawamata-Viehweg vanishing theorem. Now we assume that D≢0D\not \equiv 0.

By Lemma 2, we can find a G∼ℚtD+AG\sim_{\mathbb{Q}} tD+A such that mult⁡xG>n\operatorname{mult}_xG>n for some x∈X\Supp⁡Θx\in X\setminus \operatorname{Supp}\Theta. Then by Lemma 3, we can find a log resolution f:Y→Xf:Y\to X and an exceptional divisor PP such that f*(KX+Θ+cG)−KY+P=S+Ω−Ff^*(K_X+\Theta+cG)-K_Y+P=S+\Omega-F where SS a prime divisor, Ω\Omega an SNC divisor with coefficients less that 11, FF an integral divisor with center ⊂E\subset E. Then we have H1(Y,mf*D+F−S)=0H^1(Y,mf^*D+F-S)=0 by Remark 4. Hence the map H0(Y,mf*D+F)→H0(S,(mf*D+F)|S)H^0(Y,mf^*D+F)\to H^0(S,(mf^*D+F)|_S) is surjective. The remaining is to show that H0(S,(mf*D+F)|S)≠0H^0(S,(mf^*D+F)|_S)\neq 0 for m≫0m\gg 0. Assume that the nonvanishing holds when dimension <n<n. Note that mf*D+F−S∼ℚH+KY+Ωmf^*D+F-S\sim_{\mathbb{Q}} H+K_Y+\Omega where HH is ample. Then (mf*D−(KY+S+Ω−F))|S=m(f*D)|S−(KS+Ω|S−F|S)∼ℚH|S(mf^*D-(K_Y+S+\Omega-F))|_S=m(f^*D)|_S-(K_S+\Omega|_S-F|_S)\sim_{\mathbb{Q}}H|_S where the right hand side is ample on SS. Note that ⌈F|S−Ω|S⌉=F|S\lceil F|_S-\Omega|_S\rceil=F|_S, done. ◻

Basepoint-free

This section proves the following theorem

Theorem 6 (Basepoint-free). Let (X,Δ)(X,\Delta) be a projective klt pair, Δ≥0\Delta\ge 0. Let DD be a nef Cartier divisor such that aD−KX−ΔaD-K_X-\Delta is nef and big for some a>0a>0. Then DD is semiample.

Note that, if p|mp|m then we have Bs|mD|⊂Bs|pD|Bs|mD|\subset Bs|pD|. Our strategy is to show that for each pp, Bs|pnD|=∅Bs|p^nD|=\emptyset for n≫0n\gg 0. Let p,qp,q be two coprime integers, since every sufficiently large integer can be written as a linear combination of ps,qtp^s,q^t with nonnegative coefficients, we see that Bs|nD|=∅Bs|nD|=\emptyset for n≫0n\gg 0 hence complete the proof. So the only thing left is to show the following lemma.

Lemma 7. Use the same setting as above. If Bs|kD|Bs|kD| is nonempty for some k>0k>0, then there exists an irriducible component Z⊂Bs|kD|Z\subset Bs|kD| such that Z⊄Bs|mD|Z\not\subset Bs|mD| for sufficiently large mm.

Proof. By kodaira’s lemma, for each k≫1k\gg 1, we have aD−KX−Δ≡H+1kE,H ample, E≥0aD-K_X-\Delta\equiv H+\frac{1}{k}E, \ H\text{ ample, }E\ge 0 Hence after adjusting Δ\Delta we may assmue that aD−KX−ΔaD-K_X-\Delta is ample. Take a log resolution f:Y→Xf:Y\to X such that f*|kD|=|M|+Ff^*|kD|=|M|+F where |M||M| is basepoint-free and FF is the fixed part. write KY+ΔY=f*(KX+Δ)K_Y+\Delta_Y=f^*(K_X+\Delta) then use the same trick as in lemma 3 there exists an exceptional divisor PP and a rational number 0<c<10<c<1 such that

(1) −P-P is ff-ample and f*(aD−KX−Δ)−Pf^*(aD-K_X-\Delta)-P is ample;

(2) ΔY+P+cF=S+Ω−E\Delta_Y+P+cF=S+\Omega-E where SS is a prime divisor, Ω\Omega is SNC with coefficients less that 11, EE is an integeral divisor with f*E≤⌈−Δ⌉f_*E\le \lceil -\Delta\rceil.

Then we have mf*D+E−S−Ω−KY=mf*D−(ΔY+KY+P)−cF∼mf*D−(ΔY+KY+P)+cM−ckf*D=(m−ck−a)f*D+f*(aD−Δ−KX)−P+cM\begin{align*} mf^*D+E-S-\Omega-K_Y&=mf^*D-(\Delta_Y+K_Y+P)-cF \\ &\sim mf^*D-(\Delta_Y+K_Y+P)+cM-ckf^*D \\ &=(m-ck-a)f^*D+f^*(aD-\Delta-K_X)-P+cM \end{align*} where (m−ck−a)f*D+cM(m-ck-a)f^*D+cM is nef when m≥ck+am\ge ck+a and hence the last one is ample. By Kawamata-Viehweg vanishing theorem, we have H1(Y,mf*D+E−S)=0H^1(Y,mf^*D+E-S)=0 and hence the map H0(Y,mf*D+E)→H0(S,(mf*D+E)|S)H^0(Y,mf^*D+E)\to H^0(S,(mf^*D+E)|_S) is surjective. So use the same argument as in Theorem 5, we find a non zero section in H0(S,(mf*D+E)|S)H^0(S,(mf^*D+E)|_S). Then, we lift it in H0(Y,mf*D+E)H^0(Y,mf^*D+E). This section is nonvanishing along SS and the image of this section in H0(X,mD+⌈−Δ⌉)⊂H0(X,mD)H^0(X,mD+\lceil -\Delta\rceil)\subset H^0(X,mD) is nonvanishing alone f(S)f(S). Observe that SS is exceptional and its center is contained in Bs|kD|Bs|kD|. Hence we can take Z=f(S)Z=f(S) to complete the proof. ◻
